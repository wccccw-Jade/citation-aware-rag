# PubHealth Item 6238

Dataset source id: 6260
Document id: 9871

Fact-check label: mixture

Evidence and explanation:
Without explaining the novelty of this new research, we’re given the hope without the real reason. The piece provides a number of important specifics about the evidence and tries to wrap the study in historical and geographical context. But there are enormous holes in that context, which we point out in this review — enough holes that the novelty of this particular study is a total mystery. It’s unclear how it fits into the prior evidence base that’s described, nor what it means that the supplement is already widely used for depression in Europe. (Spoiler: The true novelty is that this is the first placebo-controlled trial in which oral SAMe was added to antidepressant therapy.)
